* Olli's dotfiles - Windows and Wsl

** Installation

Clone or download to ~/dotfiles

*** Windows

Open powershell with admin priviledges

Set executionPolicy to allow running script:
#+begin_src shell
Set-ExecutionPolicy RemoteSigned
#+end_src



Start script, you need to select profile with parameter -p, below example we are using "basic"
#+begin_src shell
.\bootstrap.ps1 -p "basic"
#+end_src

*** Wsl

Open wsl terminal

set script file executable
#+begin_src shell
chmod +x bootstrap.sh
#+end_src

Start script, you need to select profile with parameter -p, below example we are using "basic"
#+begin_src shell
sudo ./bootstrap.sh -p "basic"
#+end_src
