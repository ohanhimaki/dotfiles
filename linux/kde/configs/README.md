# KDE-asetusten kopiot

`../backup_kde.sh` kopioi tähän nimetyt KDE-asetukset käyttäjän `~/.config/`-
hakemistosta. Tarkista konekohtaiset polut ja yksityiset tiedot ennen committia.
Skripti korvaa aiemmat kopiot; Git säilyttää vain commitoidun historian.

Palautusskripti ei tällä hetkellä rajaa kopiointia asetustiedostoihin, vaan
kopioi myös tämän README:n. Tarkista [rajoitteet](../README.md) ennen käyttöä.
